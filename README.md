# Construir un radián

Actividad guiada: construir un radián trazando el radio y acostándolo sobre la curva.

Autora: Dra. Dalia Imelda Castillo Márquez
Universidad Autónoma de Nayarit · Unidad Académica de Ciencias Básicas e Ingenierías
ORCID: https://orcid.org/0000-0002-5890-0437

## Contenido

    index.html    la actividad completa (un solo archivo)
    .nojekyll     archivo vacío que GitHub Pages necesita

Es un archivo autónomo: se abre en cualquier navegador, también desde el celular, y no
requiere instalación ni conexión a un servidor especial.

## Publicarlo en Netlify

1. Cree su cuenta en https://netlify.com e **inicie sesión antes de subir nada**.
   Si sube sin sesión, el sitio se borra en una hora.
2. Entre a https://app.netlify.com/drop y arrastre **esta carpeta completa**.
3. En el panel: **Site configuration** → **Change site name**, por ejemplo `construir-un-radian`.
4. Para actualizar: en **Deploys**, arrastre otra vez la carpeta. La dirección no cambia.

## Publicarlo en GitHub Pages

1. **+** → **New repository**. Nombre: `construir-un-radian`. Marque **Public** y **Add a README file**.
2. **Add file** → **Upload files**. Arrastre `index.html` y `.nojekyll`. **Commit changes**.
3. **Settings** → **Pages**. *Source*: **Deploy from a branch**; *Branch*: **main**,
   carpeta **/ (root)**. Guarde.
4. La dirección queda como `https://SU-USUARIO.github.io/construir-un-radian/`
